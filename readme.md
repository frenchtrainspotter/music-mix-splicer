# Music-mix-splicer
A Bash script using FFmpeg to split music mixes from a single file into multiple named files, with a single command and without re-encoding.

## Warning
This is my first Bash script and it is currently very small, and **it has almost no error handling or argument validation, do not use it blindly!**
Furthermore, until the first stable release, breaking changes in syntax may happen without regards to semantic versioning.

## Features
Currently, this is a script with very few features.
- Split your mix in an unlimited number of files, named however you want
- Choose codec (and thus whether to re-encode or not)

## Planned features
- Actual error handling and argument validation
- ID3 tagging
